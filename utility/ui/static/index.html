How to check this yourself

  1. The page's Content-Security-Policy, as served by this process:
    
          connect-src 'self' means your browser refuses any network request to another origin. That includes Portabase and Supabase.
    2. 
        
  2. Open DevTools, go to the Network tab, and press Refresh. Every request goes to .
    3. 
        
  3. The CLI listens only on the loopback address. Check with
          
    netstat -ano | findstr 
    
          It shows 127.0.0.1, never 0.0.0.0.
    4. 
        
  4. The data behind this page comes from the portabase process on this machine. It uses the credentials already in your shell, connects directly to your Supabase project, and sends back names, counts, and sizes only.
    5. 
        
  5. The page is read-only. The server accepts only GET requests and has no endpoint that backs up, restores, or deletes anything.
    6.
